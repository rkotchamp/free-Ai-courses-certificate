# Contributing

Thanks for helping improve this list.

## Rules for new courses

- Link only to the official course/provider page.
- Do not add duplicate links.
- Confirm the course is free to access.
- Be honest about certificate status:
  - free certificate
  - free badge
  - free course but paid exam/certificate
  - free learning resource with no certificate confirmed
- Prefer large official providers first, then expand to universities, nonprofits, and trusted education platforms.

## Weekly update checklist

- [ ] Verify each new link is official.
- [ ] Run the duplicate-link checker.
- [ ] Confirm free access and certificate/badge status.
- [ ] Keep descriptions short and factual.
