## How to add a course

Before adding a course or certificate:

1. Use the official course/provider URL.
2. Check the existing list to avoid duplicate links.
3. Confirm the course is free to access, or clearly state if only the learning material is free and the exam/certificate is paid.
4. Prefer official providers first: Google, Microsoft, IBM, AWS, NVIDIA, Intel, Meta, OpenAI, Anthropic, DeepLearning.AI, Kaggle, universities, and recognized nonprofits.
5. Add a short description and certificate/badge status.

Suggested format:

```md
| Provider: Course Name | Official course link | What you learn | Free certificate/badge status |
```
